# HCI & Accessibility Audit — Alert services & audit screens

Standards applied: `docs/design/hci-android-guidelines.md` (§2–§6) and `docs/design/m3-expressive-research.md` §3, §6, §8 (motion), §9 (adaptive), §10 (accessibility). Shared seams inspected: `ui/components/UnitedScreenHeader.kt`, `ui/components/PullToRefreshContent.kt`, `ui/components/LoadingScreen.kt`, `ui/components/expressive/ExpressiveFilterBar.kt`, `ui/homepage/instancesettings/advanced/AdvancedSystemSettingsScreen.kt` (ExpressiveSection/ExpressiveInfoCard/InfoRow), `ui/theme/AdaptiveTheme.kt`, `ui/theme/AppTheme.kt`, plus the six backing ViewModels.

Contrast ratios below are computed from the actual token values (M3 baseline roles + the overrides in `AppTheme.kt`), using the WCAG relative-luminance formula; they should be re-confirmed with Accessibility Scanner on device.
